# Colour

Style UI with **semantic tokens only**: `var(--bg-surface)` in CSS, `bg-(--bg-surface)` and `text-(--text-secondary)` in Tailwind. No hex values, no Tailwind palette colours, no `dark:` overrides: the light and dark themes swap every token at once (`.dark` on `<html>`; use the Theme switch in the toolbar). The one exception is registration-plate yellow (`bg-plate`).

Text uses two colours, `--text` and `--text-secondary`, and never fades with opacity. Tone colours (critical, success, warning, caution, info) are for status only.
