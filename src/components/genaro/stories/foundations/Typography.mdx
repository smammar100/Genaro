# Typography

Type follows the **Fluid Functionalism** scale (`src/lib/type-scale.ts`): six roles, each one size and one line height. Nothing is larger than 24px. Set type with a role, never with a hard-coded size, line height or letter-spacing.

Sizes and line heights are CSS variables: `--fs-body` and `--lh-body`, and the same for every role. In CSS, write `font-size: var(--fs-caption); line-height: var(--lh-caption)`, never pixels.

## Typefaces

- **Geist** for all text (`font-sans`, `var(--font-sans)`), loaded by `next/font` in `app/layout.tsx`.
- **Geist Mono** wherever a mono face is used (`font-mono`, `var(--font-mono)`): registration plates.
- **Codes** such as stock IDs, VINs, invoice numbers and usernames use `font-code`: Geist with tabular (even-width) figures.
- Never Helvetica or Inter, in the app, emails or PDFs. PDFs register Geist themselves (`src/components/pdf/fonts.ts`).

## Rules

- **Two text colours.** `--text` for primary text, `--text-secondary` for secondary text. Never opacity. Tones (critical, success…) only for status.
- **Sentence case.** No uppercase, no letter-spacing, no eyebrow labels above titles: a section starts with its title.
- **Wrapping.** Headings balance (`text-wrap: balance`) and paragraphs wrap pretty (`text-wrap: pretty`), both set globally.
- **Numbers that change** (counts, money, days) use `tabular-nums`, so the words after them don't move.
- **Exceptions:** reg plates, avatar initials and printed PDFs keep their own sizes.
